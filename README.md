# AquaPure Pool Care: Pool Cleaning Website

A modern, fully responsive single-page website for a pool cleaning and maintenance company. Built as a client demo with a clean water-themed design, an interactive before/after slider, and a conversion-focused layout.

**Live Demo:** [Add your link here]

---

## Features

- **Interactive Before & After Slider**: draggable handle with mouse, touch, and keyboard support, with 3 switchable examples (Green Pool Recovery, Stained Tile Cleaning, Cloudy Water Fix)
- **Services Section**: 6 service cards with icons and hover effects
- **How It Works**: 4-step timeline (horizontal on desktop, vertical on mobile)
- **Pricing Plans**: 3 tiers with a highlighted "Most Popular" plan
- **Customer Reviews**: auto-rotating, swipeable testimonial carousel
- **FAQ Accordion**: 6 common customer questions
- **Quote Request Form**: client-side validation and success message
- **Animated Stat Counters** and scroll-reveal animations
- **Floating Call Button** (mobile) and Back to Top button
- **SEO Ready**: meta tags, Open Graph, semantic HTML5, LocalBusiness JSON-LD schema

## Tech Stack

- HTML5
- CSS3 (CSS variables, Grid, Flexbox)
- Vanilla JavaScript (no frameworks or heavy libraries)
- Google Fonts: Poppins and Inter

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/Ahmaiiiiii1/aquapure-pool-care-website.git
   ```
2. Open `index.html` in your browser. No build step required.

## Customization

- **Brand colors:** edit the CSS variables at the top of the stylesheet
- **Business details:** search for `REPLACE:` comments to update the name, logo, phone, email, and address
- **Before/After photos:** replace the images in `/images` (keep the same filenames and use matching framing and size, e.g. 1600×900)
